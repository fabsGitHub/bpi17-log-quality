# Event log data

The BPI Challenge 2017 event log is not bundled with this repository. Obtain it
from the [official 4TU.ResearchData record](https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b)
and follow the record's terms of use. Place the downloaded XES file in
`data/raw/` and keep the original file unchanged.

The scripts write generated logs to a path you choose. For example, use
`data/processed/noisy.xes` and `data/processed/repaired.xes`. Local data and
generated outputs are ignored by Git so this repository does not redistribute
the source event log or derived event-level records.

## Citation

van Dongen, B. F. (2017). *BPI Challenge 2017*. Eindhoven University of
Technology. 4TU.ResearchData. https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b
