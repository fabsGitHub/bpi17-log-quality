# Project origin and attribution

This repository is a focused portfolio rework of a university team project. It
contains a new implementation limited to the timestamp-anomaly and
activity-label-pollution contributions attributed to Fabian Hensel in the
original project report. The other team members' modules, notebooks, report,
and commit history are not included.

The BPI Challenge 2017 event log is a separate dataset published by
4TU.ResearchData. It is not included here; see [`data/README.md`](data/README.md)
for its source and citation.

The original group repository did not contain a code license. This rework does
not add a license; reuse rights should be clarified with the author before
redistribution or modification.
